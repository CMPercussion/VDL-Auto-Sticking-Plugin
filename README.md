# VDL-Auto-Sticking-Plugin
This is a Sibelius plugin that will automatically add stickings to the selected range of bars by scraping the note heads. This is only compatible with Virtual Drumline's Manual Instrument banks and relays on the percussion layouts provided by TheWriteScore.

Download the ZIP file and follow the installation instructions inside.

This is still a BETA of this plugin, but it has been perfectly functional so far. Please try it out on an unimportant test score first, and please save your work before running the plugin! I would hate to find a bug that caused Sibelius to crash and someone lose their work!
